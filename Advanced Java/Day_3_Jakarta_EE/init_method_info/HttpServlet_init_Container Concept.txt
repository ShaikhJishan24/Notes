1) There are two init() methods with HttpServlet
	public void init()
	public void init(ServletConfig config) -  it calls the init() with no parameter method

2) Web Container before invoking init method , creates ServletConfig  (ServletConfig implementation) and stores any init parameter set inside it.

3) Web Container invokes "init(ServletConfig config)" method of HttpServlet by passing ServletConfig implementation.

4) HttpServlet's "init(ServletConfig config)" method invokes "init()" method of its own.





-- 
- not Override any init() method 
- we can override init without parameter
- we can override init with parameter but we have to either save the servletoconfig instance or give it to the parent through super.init() otherwise you will get the null pointer exception
