

Go to ARC and type

http://localhost:8080/actuator/mappings
	this will show all the mappings available in your spring boot application.

one of the mappings available with your application:



 "servlets": [
          {
            "mappings": [
              "/"
            ],
            "name": "dispatcherServlet",
            "className": "org.springframework.web.servlet.DispatcherServlet"
          },


This is because we have a RestController with "/" mapping


@RestController
public class HelloController {

    @GetMapping("/")
    public String index() {
        return "Welcome to Spring Boot!";
    	
    }

}
