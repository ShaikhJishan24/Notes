-- Exception Handling 

	1) @ControllerAdvice - creates other package and class 
                     - class-level annotations
		     - Also creates methods that we create in @ExceptionHandler method

		- @ControllerAdvice is a global exception handling annotation. It allows you to handle exceptions across all controllers in one place.

		- You create one separate class:

			@ControllerAdvice
			public class GlobalExceptionHandler {

    				@ExceptionHandler(NullPointerException.class)
				public String handleNull(NullPointerException ex) {
    					return "nullError";
				}
			}

		  -- Now all controllers automatically use this handler. Whenever NullPointerException occurs in any controller → this method runs.

		- For RestAPI used
	
			@RestControllerAdvice

	2) @ExceptionHandler(ExceptionName.class) - create method for each exception handling or Exception.class for All exception

-- safe and idempotent methods

	- Safe methods
		which do not change any state on the server. e.g. "GET" method

	- Unsafe methods
		which do change state on the server
		e.g. "POST","PUT" and "DELETE"


	- Idempotent methods
		first time they change the state on the server , but if you call them again and again they don't change anything on the server. e.g. "PUT" 		and "DELETE".

	- Non-Idempotent methods
		every time you call them they will change the state on the server. e.g. "POST"

		{
			"name":"Sachin",
			"age":48
		}

		with this JSON body if you click "POST" again and again , it will insert new record every time with the same data.

-- Difference Between the RequestParam and Param 

	1. @RequestParam
		
		- is used to extract query parameters or form data from an HTTP request and bind them to method parameters in a controller.

		- public String getUser(@RequestParam("id") int id) {


	2. (@Param() String name) - used With JPA only
		
		- it is Used to bind method parameters to JPQL or SQL query parameters.

		- @Query("SELECT u FROM User u WHERE u.fName = :name")
		  List<User> findByName(@Param("name") String name);

	3. @PathVariable
	
		- It is used to extract values from the URL path and bind them to method parameters in a controller

			@GetMapping("/user/{id}")
			public String getUser(@PathVariable("id") int id) {
    				return "User ID: " + id;
			}

		- @RequestParam			@PathVariable
		  Query parameter		URL path
		  /user?id=10			/user/10

				password
				roles / authorities
				account status


                - public class CustomUserDetails implements UserDetails {

    private User user;

    public CustomUserDetails(User user) {
        this.user = user;
    }

    @Override
    public String getUsername() {
        return user.getUsername();
    }

    @Override
    public String getPassword() {
        return user.getPassword();
    }

    @Override
    public Collection<? extends GrantedAuthority> getAuthorities() {
        return List.of(new SimpleGrantedAuthority("ROLE_USER"));
    }

    @Override
    public boolean isAccountNonExpired() { return true; }

    @Override
    public boolean isAccountNonLocked() { return true; }

    @Override
    public boolean isCredentialsNonExpired() { return true; }

    @Override
    public boolean isEnabled() { return true; }
}

-- What is CommadLine Runner

	- CommandLineRunner is a Spring Boot interface used to run some code automatically after the Spring application has started.

		In simple words:

			- It runs code once, immediately after the application context is loaded.

	- @SpringBootApplication
	  public class DemoApplication implements CommandLineRunner {

    		@Override
    		public void run(String... args) throws Exception {
        		System.out.println("Application started successfully");
    		}

    		public static void main(String[] args) {
        		SpringApplication.run(DemoApplication.class, args);
    		}
	}
