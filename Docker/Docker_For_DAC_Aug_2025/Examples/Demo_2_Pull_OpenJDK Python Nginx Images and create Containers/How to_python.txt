let's now create a container from python image and also open it in an interactive mode.

	docker run --name mypythoncontainer -it python

[ This command does the following:

Runs the Python image (python).
The -it flag allows you to interact with the container’s terminal, so when the container starts, you'll be inside an interactive Python shell.

The --name mypythoncontainer gives the container a specific name (mypythoncontainer), which you can later reference to manage or stop it.
]
