after project gets created add one java class inside "com.example.demo"



package com.example.demo;

import java.util.HashMap;
import java.util.Map;

import org.springframework.web.bind.annotation.RestController;
import org.springframework.web.bind.annotation.GetMapping;

@RestController
public class TestController 
{
	@GetMapping(value = "/getValues")
	public Map<String,Object> getValues()
	{
		Map<String,Object> data=new HashMap<String,Object>();
		data.put("message","Java API is working fine");
		data.put("languages","Java,Python,Javascript");
		data.put("code", "2345");
		return data;
	}
}



go to "application.properties" file and change the port no.

server.port=9595

now run the spring boot application 

go to the browser and type

http://localhost:9595/getValues

and check if it's working properly or not

you should get the output

{"code":"2345","languages":"Java,Python,Javascript","message":"Java API is working fine"}

REPOSITORY                 TAG       IMAGE ID       CREATED          SIZE
springbootimage1            latest    905b408e705f   27 seconds ago   490MB



now let's run this image so that container will get created


docker run --name bootcontainerr1 -p8002:9595  springbootimage1


	[ above command sends a request to http://localhost:8002 to Docker which is
set up to "listen" for traffic on port 8002 of the host.
Docker forwards the request to port 9595 inside the container where the Spring Boot application is running. ]


9595 → Port on which Spring Boot runs inside the container

8002 → Port exposed on your laptop (host machine)

	 Inside container → Spring Boot listens on 9595
	 Outside (browser / Postman) → You access using 8002


go to the browser and type:

http://localhost:8002/getValues
	
	make sure you get the output
you should get the output



{"code":"2345","languages":"Java,Python,Javascript","message":"Java API is working fine"}
