findAny()

Returns any element, mostly useful for parallel streams.

List<Integer> nums = List.of(10, 20, 30, 40);

Optional<Integer> result = nums.stream()
                               .findAny();

System.out.println(result.get());


----------
anyMatch()

Checks if any element matches a given condition.
Returns true/false.

List<Integer> nums = List.of(10, 20, 30, 40);

boolean found = nums.stream()
                    .anyMatch(n -> n > 25);

System.out.println(found);

✔ Output:
true


Because 30 and 40 are > 25.
